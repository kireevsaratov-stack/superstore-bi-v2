# Superstore BI — контекст для Claude Code

Streamlit-дашборд анализа продаж (датасет Superstore, 2014–2017). Читать вместе с
`README.md` (что показывает и как считается) и `docs/CHANGELOG.md` (история).
Если есть `notes/local-context.md` — прочитать его следующим: там договорённости владельца,
резервные копии и локальные пути (папка не публикуется).

## Архитектура

- `app.py` — только раскладка: шапка → годы/валюта → KPI → 4 ряда по 2 блока → прогноз → экспорт.
  Streamlit выполняет его целиком при каждом клике; тяжёлое — в `@st.cache_data`
  (`get_sales(currency)`, `get_forecast()`), экспорт — `download_button(data=callable)`.
- `superstore/` — всё, кроме `ui.py`, без Streamlit: чистые функции, их проверяют тесты.
  Новый расчёт → функция в `analytics.py` + тест; новый график → функция в `charts.py`.
- Главная таблица в `app.py` — `df`: выбранные годы, нужная валюта. Все блоки читают её.
  Исключение — прогноз: всегда полная история в $ (см. `forecast.py`).

## Правила

- Главную страницу не раздувать: новое — вкладками внутри блока, раскрывашками или отдельной страницей.
- Цвета — только константы из `superstore/config.py`.
- Блок — `with ui.card('ключ', 'Заголовок'):` (CSS цепляется к классу `st-key-card-*`).
- Подписи — через `ui.caption()`: он экранирует `$` (два `$` Streamlit рендерит как формулу).
- Авто-выводы (`*_text` в `analytics.py`) считаются из данных, без захардкоженных чисел;
  числительные — через `plural()`.
- Мобильная вёрстка (`@media max-width:768px` в `ui.py`): графики статичны
  (`pointer-events:none`), KPI в 2 колонки. Не ломать.
- Тема светлая, зафиксирована в `.streamlit/config.toml` — не переопределять CSS `!important`.
- Секреты — только Streamlit Secrets (`.streamlit/secrets.toml` в .gitignore).
- Интерфейс, комментарии и коммиты — на русском; коммиты осмысленные.

## Команды

```bash
.venv/bin/streamlit run app.py              # локально, http://localhost:8501
.venv/bin/python -m pytest                  # 38 тестов, ~15 с
.venv/bin/python scripts/fetch_cbr_rates.py # перекачать курсы ЦБ (обычно не нужно)
```

Превью в Claude Code: `.claude/launch.json`, конфигурация `superstore`.

## Грабли

- **Правки в `superstore/*.py` dev-сервер может не подхватить** (перезапускает `app.py`,
  но держит старый модуль) → после правок пакета перезапустить сервер.
- **Версии закреплены** (`requirements.txt`). Обновлять осознанно: поменять → `pip install -r
  requirements-dev.txt` → pytest → браузер. Нужен Python ≥ 3.11 (pandas 3); numpy 2.5 уже требует 3.12.
- **Зеркало `cbr-xml-daily.ru` не использовать** — не отвечает. Курсы — только официальный `cbr.ru`
  через `scripts/fetch_cbr_rates.py`, в рантайме сети нет.
- **Прогноз не учить на выбранных годах** — на подвыборках Holt-Winters выдаёт мусор
  (1 год → +73%, годы с разрывом → нули в ряду). Минимум 24 месяца, бэктест — 36.
- Treemap с горизонтальной шкалой цвета однажды не нарисовался, когда страница грузилась
  в скрытой панели; при обычной загрузке рисуется. Если всплывёт — убрать `colorbar`.
- 9994 — это **строки** заказов; заказов 5009, клиентов 793.
- `st.pills` в AppTest не имеет обёртки: годы задаются через `at.session_state['years']`.
