# История изменений

## v3 — 2026-09-29: рефакторинг и исправления

Набор блоков и оформление прежние; исправлены расчёты, скорость и устойчивость.

- Код: `app.py` → раскладка страницы + пакет `superstore/` (данные, расчёты, прогноз, графики,
  оформление); 38 тестов (pytest + прогон страницы через Streamlit AppTest).
- Рубли: официальные дневные курсы ЦБ в файле, пересчёт по курсу на дату заказа; приложение
  не ходит в сеть (раньше — живые запросы к стороннему зеркалу курсов, которое перестало отвечать).
- Прогноз: всегда обучается на полной истории; бэктест сравнивает модель с наивным прогнозом
  «как год назад» (раньше модель училась на выбранных годах и на подвыборках ошибалась).
- Выводы: подписано, с чем сравниваются дельты KPI; вывод Парето различает заработанную
  и итоговую прибыль и показывает убыток от убыточных товаров.
- Скорость: экспорт в CSV/Excel собирается по нажатию кнопки; отклик страницы ~2,8 с → ~0,8 с.
- Совместимость: версии библиотек закреплены (Python ≥ 3.11), устаревший API Streamlit заменён.
- Репозиторий: `.gitignore`, из git убраны служебные файлы IDE и ОС.

## v2 — май 2026: одностраничный мобильный дашборд

Редизайн: одна страница, выбор годов «таблетками», KPI-строка, тонкие рамки блоков.
Топ-15 товаров, Парето с линией 80%, treemap структуры, география (бары + пузырьковая карта),
авто-выводы под графиками, статичные графики на телефоне, светлая тема.

## v1 — май 2026: первая версия

Отдельный репозиторий `superstore-bi`: EDA-ноутбук, сайдбар с фильтрами, 4 вкладки
(обзор, продукты и клиенты с ABC-анализом, прогноз, экспорт), рубли по курсу ЦБ, бэктест прогноза.
